SBI4atmret
==========

**Simulation-Based Inference for Atmospheric Retrieval**

SBI4atmret is a modular Python framework for neural posterior estimation (NPE)
applied to exoplanet and brown dwarf atmospheric characterization. It provides
an end-to-end pipeline from dataset generation through training to comprehensive
evaluation of posterior estimates.
